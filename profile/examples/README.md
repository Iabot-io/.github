# Ejemplos de aplicación de las skills

Casos ficticios resueltos durante la revisión del catálogo. Incluyen incidencias, datos ausentes y decisiones que el agente debe conservar para revisión. Son ejemplos, no resultados de clientes ni certificaciones.

Cada carpeta conserva las entradas y las salidas obtenidas. Los casos agrupados ejercitan más de una habilidad y, en conjunto, cubren las 22 colecciones del catálogo.

| Caso | Qué permite revisar |
| --- | --- |
| [Tesorería y comparación de ofertas](finance/README.md) | Transferencias internas, moneda pendiente, compras mínimas y ofertas comparables. |
| [Presupuesto público y agenda de cuidados](public-care/README.md) | Fases presupuestarias, solapamientos y tiempos disponibles sin decisiones clínicas. |
| [Preparación Linux y revisión de afirmaciones](tools-marketing/README.md) | Herramientas todavía no verificadas y mensajes comerciales contrastados con evidencias. |
| [Memoria arquitectónica y trazabilidad alimentaria](documents-food/README.md) | Superficies de fuentes distintas y balance de lotes con consumos pendientes de asignar. |
| [Plazos y documentación de licitación](legal-documents/README.md) | Notificación sin acreditar, calendario pendiente y correcciones parciales de requisitos. |
| [Conciliación bancaria documental](administration/README.md) | Movimientos emparejados, comisión pendiente y saldo contable de apertura sin verificar. |
| [Revisión de un levantamiento topográfico](civil/README.md) | Identificadores duplicados, cotas no numéricas y referencia vertical desconocida. |
| [Propuesta de reposición comercial](commerce/README.md) | Plazo de suministro, múltiplos de compra y ventas limitadas por falta de existencias. |
| [Certificación provisional de obra](construction/README.md) | Acumulados, correcciones sin aprobar y separación del importe propuesto y el líquido final. |
